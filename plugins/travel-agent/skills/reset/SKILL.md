travel-agent が保存したデータを消します。会話は日本語です。

データフォルダ：`${CLAUDE_PLUGIN_DATA}`
旅行ごとのデータ：`${CLAUDE_PLUGIN_DATA}/trips/<旅行ID>/`

指定：$ARGUMENTS

## 手順

1. `${CLAUDE_PLUGIN_DATA}/trips/` の下にあるフォルダを一覧します。何もなければ「保存されたデータはありません」と伝えて終わります。
2. それぞれのフォルダについて、旅行 ID と、`conditions.json` があればその日程とエリアを、1行ずつ見せます。
3. 指定がなければ、どれを消すかを聞きます（1件、複数、全部、やめる）。
4. 指定が旅行 ID なら、その1件だけが対象です。`all` なら全部が対象です。
5. **消す前に、対象のフォルダのパスを見せて、確認を取ります。** 確認が取れてから消します。
6. 消すのは `${CLAUDE_PLUGIN_DATA}/trips/` の下のフォルダだけです。それより上のフォルダや、ほかの場所のファイルは消しません。パスに `..` が含まれる指定は受け付けません。
7. 消したら、何を消したかを伝えます。

ファイルを消すツールが使えない場合は、消さずに、ユーザーが自分で消すためのコマンドを伝えます。

```
rm -rf "${CLAUDE_PLUGIN_DATA}/trips/<旅行ID>"
```

## 補足

- このスキルが消すのは、travel-agent が保存したデータだけです。Claude Code 本体が保存している会話の記録は、別に残ります。
- plugin をアンインストールすると、データフォルダごと消えます。
